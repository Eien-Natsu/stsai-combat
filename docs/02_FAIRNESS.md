# 技术参考：公开信息、采样与来源

约束和当前状态以 [主线](../PROJECT_MAINLINE.md) 为准。本文件补充技术细节，不构成独立执行计划或公平性认证。

## 三个隔离层

Observation 用白名单构造：当前手牌、公开牌区多重集、HP/格挡/能量、可见意图和状态/计数、已观察历史可用。未知抽牌区不保留真实排列，UUID/指针/真实 seed/RNG 不导出；合法已知牌顶须单独保留，不能为了“公平”丢弃玩家已知信息。
动作提示只能来自当前可见状态，不能靠执行未来随机动作得到。字段黑名单只是回归防线，把隐藏字段换名不产生合法性。
Search 的节点只依赖动作与公开观察历史；agent/split/episode-index 的独立随机命名空间不使用真实 episode_seed。采样前后公开根状态和动作集合不变，不能修改真实环境。
Training 编码只接收公开字段；backend/split/语义版本须校验，不用最终 test 训练、调参、选模型或失败挖掘。场景和随机种子可留在隔离的来源元数据中用于复现。

## 当前 native 近似

实现声明为 `public_history_candidate_sampling/2`：未来 RNG 流独立重采样；louse 等构造时隐藏攻击基础值按合法公开历史约束的候选集合采样，不能以真实隐藏值作先验/筛选条件/种子。
已经发生的公开事件与可见伤害可更新候选约束，记录真实执行事件而非仅从 turn 改变猜测历史。每 simulation 对未确定候选取值，再在该模拟内保持一致。
上游多流可能共享 seed/floor 相关结构；独立流加候选集不是原游戏的精确联合后验。零碰撞、同根观察一致或有限 seed 扫描都不能证明覆盖全部隐藏情况。
每扩大敌人/状态覆盖，需要字段审计、同公开历史不同隐藏真值的反事实、根稳定性和生命周期测试。Runic Dome/隐藏意图及未知能力必须按当前接口拒绝，不能导出引擎内部知道但玩家不知道的信息。

## 证据与复现

现有公开反例在 `tests/fixtures/ambiguity_public_trace.json`；审计产物位于 `evidence/`；入口为 `review/counterfactual_replay.py`。它们属于对应 commit 的证据，新增能力不能直接继承全面通过结论。
`CURRENT_CODE_RUN`、旧版本负对照、源码论证、未验证分开写。真实游戏轨迹必须独立于模拟器，受控规则诊断若使用隐藏真值则与公平策略数据隔离。
相同代码/配置/引擎可提供条件可重复性；跨设备数值及 GPU 训练不保证逐位一致。checkpoint 恢复也不自动保证精确数据流游标。
收集目录要求 fingerprint 一致；不并发写同一 episode 区间；teacher/目标/语义变化用新目录。manifest 与 SHA256 提供来源/完整性核对，不替代身份认证或防恶意授权。
已用开发集必须标记为已用。最终测试只有在模型选定且另获授权时创建；看过测试再调模型就不再拥有同一份未见测试。
