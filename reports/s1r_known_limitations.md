# S1R 已知限制

本文件列出本轮交付**没有被证明**的东西。写在交付包里的每个数字都受下面这些边界约束；
把这份清单读完再读 SUMMARY.md，两者是配套的。

## 1. 与原版游戏的关系：未做差分验证

- `game_differential_verified=false`，本轮没有改变这一点。本机没有合法原版游戏副本，
  G3 一类的原版一致性检查**未执行**，不是"通过"。
- 编译成功、测试通过、意图表一致，都不是"与原版一致"。模拟器规则来自锁定的上游
  `sts_lightspeed` revision `7476a819…` 加 4 个已声明的补丁；补丁本身是源码推导
  （Disarm+ 力量、A18+ Gremlin Nob 模式、事件日志、缺失的 `<algorithm>` 头文件），
  没有一条经过原版实机比对。
- 所有对外表述仍然是：**未经原游戏差分验证、使用声明采样近似的 simulator pilot**。

## 2. 信念模型是声明近似，不是原版后验

- sampler 用独立 RNG 流重建 `aiRng / cardRandomRng / miscRng / monsterHpRng / potionRng /
  shuffleRng`，且对洗牌顺序取公开多重集上的均匀随机。原版是相关流，这里不是。
- 虱子（GREEN_LOUSE / RED_LOUSE）的初始攻击基数在生成时掷出、玩家不可见。这里从
  公开区间 `[6,8]`（A20）出发，用玩家看到过的攻击显示收窄候选集，然后在候选集内**抽样一次并保留**；
  真实 `miscInfo` 从不被读取。这是"公开历史 + 均匀先验"，不是原版的联合后验。
- 显示伤害被力量压到 0 时（例如力量 -9），多个候选会同时相容，候选集**不会**塌缩到唯一值。
  这是如实保留的歧义，不是缺陷，也没有被"假装已知"隐藏。
- 除虱子外的怪物：`miscInfo`/`monsterData` 要么由公开历史决定（已注明依据），要么列在
  `sampler/field_audit.json` 的 UNSUPPORTED / 未完成证据桶里；17 个遭遇之外的怪物没有任何可达路径，
  只登记了读取点。

## 3. 扫描是覆盖回归，不是证明

- `sampler/field_audit.json` 的零碰撞统计只作 **coverage regression**。在有限可达状态上没找到反例，
  不等于"公开信息决定该字段"，也检测不出"隐藏参数未知但被判定为确定"的情形（虱子就是这一类）。
- coverage 扫描的规模是 17 个遭遇 × 8 个种子 × 30 回合（3584 个状态、93 个公开签名），
  本轮**没有**再扩大扫描，也不把它的结果当门槛。

## 4. 意图表：非原版 UI 认证

- `input/intent_mapping.csv` 的每一行是 `ENGINE_DERIVED_ONLY` 或 `UI_SOURCE_VERIFIED`（wiki 引用），
  **没有** `ORIGINAL_GAME_VERIFIED`。生成一致性只说明表与生成器一致，不等于原版 UI 一致。
- 两个 UNKNOWN 分别标注原因：`GAME_SHOWS_UNKNOWN`（公开资料说明原版显示未知图标）
  与 `MAPPING_NOT_KNOWN`（本项目尚未确认原版显示什么）。两者不混用。

## 5. 覆盖范围本身

- 23 张卡（含升级）、17 个 Act 1 遭遇、无药水、仅 Burning Blood 起始遗物。
  192 维、R1、多训练种子、数据扩容、DAgger、药水/遗物/Boss 扩展都在本轮禁止范围内，未做。
- live bridge 拒绝打虱子遭遇：单次快照无法重建其公开记忆，拒绝比伪造一个"不适用"更诚实。

## 6. 统计边界

- 训练只有一个固定种子（init_seed=17）与一份固定数据；开发集 256 个场景是**复用**的开发集，
  不是最终 test。配对 bootstrap 的区间条件于该固定模型、该固定数据与该开发集；
  跨 0 不等于证明等价，不跨 0 也不等于超过启发式。
- 本轮没有超参搜索，也没有按结果更换 checkpoint 或种子。Outcome/value 只作辅助诊断，
  不参与搜索、风险控制或选点。
- 学生与历史结果的差值不能单因素归因：输入语义、计数规则与数据轨迹在本轮同时改变。

## 7. 未使用的东西

- 未创建、未读取、未解封 P6 最终 manifest；未使用云端算力；未升级硬件或驱动；
  未使用游戏本体、资源或存档。
