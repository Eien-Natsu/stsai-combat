# S2 已知限制

本文件列出本轮**没有被证明**的东西。SUMMARY.md 里每个数字都受这里的边界约束。

## 1. 与原版游戏的关系：仍未做差分验证

- `game_differential_verified=false` 保持不变。本机没有合法原版游戏副本，原版一致性检查**未执行**。
- 模拟器 = 锁定上游 revision `7476a819…` + 5 个声明补丁。第 5 个补丁（0005）只给
  `CardManager.cpp` 加一行 `#include <algorithm>`，是为了让更严格的 libstdc++ 能编译，
  不改变任何规则。
- 所有结论仍是"未经原游戏差分验证、使用声明采样近似的 simulator pilot"。

## 2. 结论是条件性的，而且是本轮的固定预算

- 主结论只针对：**固定模型与有效 batch、最多 500 次优化更新、本轮的三个 init_seed（17/29/43）
  与这一份开发 probe**。区间条件于实际训练出的这三个 seed，**不覆盖训练随机性**；
  它也不是原游戏或超人类结论。
- 数据量不同意味着覆盖不同：500 步 × 有效 batch 32 = 16,000 行，D96 只有 1,774 行
  （约 9 遍），D384 有 6,891 行（约 2.3 遍）。D384 并没有被充分遍历。
  **因此若结果为负，只能说明"在这个固定预算下没发现收益"，不能宣称"更多数据无效"。**
  本轮不追加 1000/2000 步，也不为显著性补第四个 seed。

## 3. 复用的东西及其依据

- D96 = 原 S1R `train` index 0–95；D96-seed17 的 run 直接复用，没有重训。
  `semantic_compatibility.json` 记录了依据：0005 只增头文件，五个语义版本全部未变，
  且用新构建把 256 个开发场景重放一遍，与 S1R 记录逐场一致（胜负/效用/HP/动作数）。
- D96 分片对 S1R 交付 manifest 逐文件校验通过；这证明的是**包内来源链一致**，
  不等于向上游重新认证了全部源码。
- V24 = 原标签验证集，是全部六个 run 共同的选点集。

## 4. 开发集的复用状态

- `DEV_OLD256` 早已被 S1R 使用，本轮只作次要诊断，**不能**称未见测试集。
- `DEV_PROBE256` 在本轮训练前物化、哈希并冻结，本轮首次使用；**从被读取的那一刻起就已用掉**，
  以后不能再当作全新留出集。它不是 P6，也不调用 `make-test-manifest`。
- 两个集合与训练集、V24 之间没有相同的 (scenario, episode seed) 对（逐项比对），
  但"公开开局偶然相同"与"重复 episode"是两件事，报告里分开计数。

## 5. 权重交付范围

- 只上传 `D384_s17` 的 selected 推理权重（预先指定的复核代表，不是"最好的 seed"）。
  另外五个模型只交 run 配置、selected/last 步数与 SHA、逐场原始结果；
  **review 不能声称六个模型都独立加载验证过**，只能复算它们的逐场记录。
- D96-seed17 的权重已在上一轮交付（SHA `57ffb03f…`），本轮不重复上传。

## 6. 工具链与复现边界

- 本机是 GCC 12.2；review 报的失败发生在 GCC 14.2。0005 在本机（GCC 12）构建、
  测试全绿，而 GCC 14 下"只加这一行头文件即可编译"由 review 自己的
  `header_only_build.log` 证明。**本机没有 GCC 14，因此没有在本机复现该编译器的失败与修复。**
- `scripts/scan_std_includes.py` 的扫描显示补丁后引擎源码中已没有"用了 std 算法却没包含
  `<algorithm>`"的文件（vendored 的 nlohmann/json 测试除外，它们不参与编译）。
  这是**源码扫描**，不是对其它工具链可移植性的证明。

## 7. 仍未验证 / 未做

- 原游戏差分、更广状态空间公平性、完整的卡池/药水/遗物/Boss 覆盖、超人类能力。
- 192 维模型、容量或结构变化、reward 或 teacher 预算变化、DAgger、hybrid、leaf value、
  机制扩展、第四个训练种子、最终 P6：本轮全部未做。
- sampler 仍是声明的独立随机流 + 候选集近似，不是原版联合后验。
- 分层（按 family/遭遇）结果只作探索性统计，每个都带 n，不据此改变采样分布或宣布普遍提升。
